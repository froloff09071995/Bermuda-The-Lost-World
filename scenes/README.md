# Сцены — второй этап

Здесь поглавные планы из `chapters/` превращаются в **сцены и реплики** — основу для сценария манги/аниме или для прозы.

Один файл = одна глава, имя файла совпадает с главой в `chapters/`.

## Формат

- **Сцена N. Название** — заголовок сцены.
- *Курсив под заголовком* — место и время.
- Обычный текст — действие и описание, в настоящем времени, коротко, «камерой».
- **Имя.** Реплика. — диалог. *(ремарка)* — как сказано или что делает персонаж.
- **ГГ (мысленно).** — внутренний монолог.
- Блок кода — окно интерфейса или системное уведомление.
- `[Кадр: …]` — подсказка для важной панели манги / кадра аниме. Используется редко, только там, где кадр важен.

## Статус

Все сцены — **предложение Claude**, ждут утверждения автора. План главы в `chapters/` остаётся главным: если сцена с ним расходится, прав план.
